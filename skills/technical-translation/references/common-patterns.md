# Common Translation Patterns

Frequent scenarios and established patterns in technical document translation with examples.

## Document Structure Patterns

### Table of Contents
```
Italian: INDICE / SOMMARIO
English: TABLE OF CONTENTS / CONTENTS

Common format:
1. Introduzione → Introduction
2. Descrizione generale → General description
3. Installazione → Installation
4. Uso e funzionamento → Operation
5. Manutenzione → Maintenance
6. Risoluzione problemi → Troubleshooting
7. Dati tecnici → Technical data
8. Appendice → Appendix
```

### Section Headers
```
Capitolo → Chapter
Sezione → Section
Paragrafo → Paragraph
Articolo → Article
Punto → Point / Item
Sottoparagrafo → Subparagraph
```

## Instructional Patterns

### Step-by-Step Procedures

**Pattern:**
```
Italian: 
1. Spegnere la macchina
2. Attendere 5 minuti
3. Rimuovere il coperchio
4. Controllare il livello dell'olio

English:
1. Switch off the machine
2. Wait 5 minutes
3. Remove the cover
4. Check the oil level
```

**Common Verbs:**
- effettuare → perform / carry out
- eseguire → execute / perform
- verificare → check / verify
- controllare → check / control / verify
- rimuovere → remove
- installare → install
- smontare → disassemble / remove
- montare → assemble / install
- serrare → tighten
- allentare → loosen
- regolare → adjust
- impostare → set
- pulire → clean
- lubrificare → lubricate
- sostituire → replace
- collegare → connect
- scollegare → disconnect

### Conditional Instructions

**Pattern:**
```
Italian: 
Se la spia rossa si accende, arrestare immediatamente la macchina.
In caso di malfunzionamento, contattare il servizio assistenza.

English:
If the red indicator light comes on, stop the machine immediately.
In case of malfunction, contact the service department.
```

**Common Conditionals:**
- se → if
- in caso di → in case of / in the event of
- qualora → if / should
- quando → when
- prima di → before
- dopo → after
- durante → during

## Technical Description Patterns

### Component Description

**Pattern:**
```
Italian:
Il dispositivo è composto da:
- una base in ghisa
- un motore elettrico trifase
- un riduttore a ingranaggi
- un sistema di lubrificazione automatica

English:
The device consists of:
- a cast iron base
- a three-phase electric motor
- a gear reducer
- an automatic lubrication system
```

### Performance Specifications

**Pattern:**
```
Italian:
Potenza nominale: 15 kW
Velocità massima: 1500 giri/min
Coppia massima: 95 Nm
Rendimento: ≥ 90%

English:
Rated power: 15 kW
Maximum speed: 1500 rpm
Maximum torque: 95 Nm
Efficiency: ≥ 90%
```

**Common Specification Terms:**
- nominale → rated / nominal
- massimo → maximum
- minimo → minimum
- intervallo → range
- campo di funzionamento → operating range
- condizioni nominali → rated conditions
- condizioni di esercizio → operating conditions

## Warning Patterns

### Standard Warning Format

**Pattern 1: Procedural Warning**
```
Italian:
AVVERTENZA
Prima di eseguire qualsiasi operazione di manutenzione, scollegare 
l'alimentazione elettrica e attendere almeno 5 minuti.
Il mancato rispetto di questa avvertenza può causare lesioni gravi 
o morte per folgorazione.

English:
WARNING
Before performing any maintenance operation, disconnect the power 
supply and wait at least 5 minutes.
Failure to follow this warning may result in serious injury or 
death from electric shock.
```

**Pattern 2: Hazard Warning**
```
Italian:
PERICOLO
Organi in movimento
Tenere mani e indumenti lontani durante il funzionamento

English:
DANGER
Moving parts
Keep hands and clothing clear during operation
```

## Table Patterns

### Technical Data Tables

**Header Row Pattern:**
```
Italian Headers:
Parametro | Valore | Unità | Note

English Headers:
Parameter | Value | Unit | Notes
```

**Common Table Elements:**
- valore nominale → rated value
- min / max → min / max
- range → range
- tolleranza → tolerance
- condizioni → conditions
- specifiche → specifications
- caratteristiche → characteristics / features

### Maintenance Schedule Tables

**Pattern:**
```
Italian:
Operazione | Frequenza | Note
Controllo livello olio | Giornaliero | Prima dell'avviamento
Sostituzione olio | Ogni 2000 ore | Usare olio consigliato
Pulizia filtri | Settimanale | O quando necessario

English:
Operation | Frequency | Notes
Oil level check | Daily | Before starting
Oil replacement | Every 2000 hours | Use recommended oil
Filter cleaning | Weekly | Or when necessary
```

```
English:
```

**Pattern:**
```

- the website www.example.com
```

## Troubleshooting Patterns

### Problem-Cause-Solution Table

**Pattern:**
```
Italian:
Problema | Possibile causa | Soluzione
La macchina non si avvia | Mancanza di alimentazione | Verificare il collegamento elettrico

English:
Problem | Possible Cause | Solution
Machine does not start | No power supply | Check electrical connection
```

### Diagnostic Steps

**Pattern:**
```
Italian:
1. Verificare che...
2. Controllare se...
3. Se il problema persiste...
4. In caso contrario...
5. Contattare il servizio assistenza

English:
1. Verify that...
2. Check if...
3. If the problem persists...
4. Otherwise...
5. Contact the service department
```

## Notes & Remarks Patterns

### Important Notes

**Pattern:**
```
Italian:
NOTA: Questa operazione deve essere eseguita da personale qualificato.
IMPORTANTE: Non superare i valori massimi indicati.
ATTENZIONE: Pericolo di danneggiamento dell'apparecchiatura.

English:
NOTICE: This operation must be performed by qualified personnel.
IMPORTANT: Do not exceed the indicated maximum values.
NOTICE: Risk of equipment damage.
```

## Common Sentence Structures

### Obligation/Requirement

**Pattern:**
```
Italian:
È necessario / occorre / bisogna → It is necessary / must / need to
Deve essere → Must be / Shall be
È obbligatorio → It is mandatory / compulsory
È vietato → It is forbidden / prohibited

Example:
È necessario indossare i DPI → PPE must be worn
```

### Recommendation

**Pattern:**
```
Italian:
Si raccomanda di → It is recommended to
Si consiglia di → It is advised to
È preferibile → It is preferable

Example:
Si raccomanda di verificare il livello dell'olio → 
It is recommended to check the oil level
```

### Permission/Prohibition

**Pattern:**
```
Italian:
È consentito → It is permitted / allowed
Non è consentito → It is not permitted / not allowed
È vietato → It is forbidden / prohibited

Example:
Non è consentito modificare i dispositivi di sicurezza →
It is not permitted to modify safety devices
```

## Quality Control Language

### Inspection & Testing

**Pattern:**
```
Italian:
conforme alle specifiche → meets specifications / complies with specifications
non conforme → non-compliant / does not comply
entro tolleranza → within tolerance
fuori tolleranza → out of tolerance
superato / passed → passed
respinto / failed → failed
da verificare → to be verified
approvato → approved
```
