# ShipLabelApp – appunti di installazione (2023)

- Server di produzione: APP01. Server di test: APPTEST01.
- La sessione verso le API del gestionale dura 60 minuti.
- Stampa tramite LabelPrintService su PRN01.
- Le stampanti degli utenti si configurano nella tabella ACM_USER_PRINTERS (colonne UserName, PrinterName).
