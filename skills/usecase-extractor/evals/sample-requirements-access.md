# Meeting Room Booking System — Access Addendum

Requirements addendum to the main requirements document (`sample-requirements.md`).

## §A1 Reception Check-in

Visitors must be checked in by a receptionist at the floor desk. Checking in a visitor
creates a one-day access badge linked to the meeting the visitor attends.

## §A2 Badge Synchronization

The access-control system synchronizes room access rights nightly with the active
bookings. A canceled booking removes the room access right at the next synchronization.

## §A3 Host Notification

When a visitor is checked in, the system notifies the hosting employee in the chat tool.
