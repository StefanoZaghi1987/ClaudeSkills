Technical Summary Generator is a Claude project that transforms any technical document — including manuals, specification sheets, safety guides, scientific articles, and user manuals — into a detailed, well-structured summary report. It accepts input as file attachments or website URLs, automatically analyzes the content through an 8-phase processing workflow, and generates a downloadable output in the user's chosen language (default: Italian) and format (Word .docx, PDF .pdf, or Markdown .md). The report is organized into three mandatory sections: Introduction, Discussed Topics, and Summary. User interaction is minimal: only language and output format selection are required.
