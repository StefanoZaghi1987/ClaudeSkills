This project maintains documentation, specifications, implementation plans and code comments on a large, long-lived codebase worked by AI coding agents inside a fixed brainstorm-to-implementation workflow. It addresses one failure mode: asked to change a statement, an agent appends a revision instead of editing it. Appending is always safe; deleting demands knowledge the agent lacks. Documents accumulate layers that contradict each other with no signal saying which is current, and the enemy is contradiction rather than length. The remedy is an artifact taxonomy that separates state from history - specs and comments describe the present, plans are ephemeral, decision records are append-only - carried by rules that prevent accumulation and skills that repair what accumulated anyway. Rules apply always, at zero activation cost; skills are rare, multi-phase procedures with real risk of information loss; anything a shell command could do is a script or a hook. Expected output: a compact rule set, two consolidation skills, a per-pass procedure, mechanical verification scripts and gates, and diff-based human review checklists. Every control here is mechanical, states what it does not verify, and is floored by something the agent did not author.
